# Support

Thanks for using transactional-messaging! We're glad it's useful to you.

This project is shared as-is as part of commercetools-labs. It isn't a commercetools product and isn't covered by commercetools support, so we can't promise replies, fixes or timelines.

That said, issues and pull requests are very welcome, and we'll look at them when we can.

If you need something sooner:

- Fork the repository and adapt it to your needs. That's what it's here for.
- Ask in the commercetools community.
- For questions about the commercetools platform itself (APIs, Connect, the Merchant Center), use commercetools support as usual.
- For Twilio or SendGrid account questions, contact Twilio support.
